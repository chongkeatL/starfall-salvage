# Starfall Salvage

Starfall Salvage is an open-source 2D Canvas browser shooter written in vanilla JavaScript ES modules, with no framework and no backend. It is designed to be deterministic and testable. The planned v1.0.0 includes a player ship, bullets, asteroids that split on death, drones that chase and ram, salvage drops and pickup, and escalating waves.

> **Work in progress.** This project is under active development.

## Planned controls

**Keyboard**
- Move: arrow keys or WASD
- Fire: Space
- Start (from the ready screen): Space or Enter
- Pause: P or Esc
- Restart: R

**Touch (planned)**
- Left-zone stick to move
- Fire button
- Tap to start
- Pause and restart buttons

## Running the tests

```
npm test
```

Requires Node 22 or newer.
